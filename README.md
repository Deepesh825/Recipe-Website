# FlavorNest

A basic recipes website created using HTML and CSS. Explore recipes with smooth hover effects and an elegant gradient design.

## Technology Used

- **HTML5**
- **CSS3**

## Features

- Responsive navigation bar
- Recipe categories with list of ingredients and instructions
- Hover effect on recipe images
- Gradients throughout the user interface with custom color palette
- Branding footer
- Centered and clean layout

## Running the Application

1. Fork this repository or download it.
2. Open the `index.html` file in any web browser.
3. No need for any external library or dependencies.
